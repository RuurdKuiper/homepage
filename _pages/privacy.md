This website uses [GoatCounter](https://www.goatcounter.com/) to understand how
many people visit, which pages are useful, and which countries visitors come
from. The analytics dashboard is intended for the site owner and is not embedded
on this website.

GoatCounter can collect aggregate statistics about visited pages, referring
websites, approximate location, browsers, operating systems, languages, and screen
sizes. It does not set analytics cookies. IP addresses are used to estimate
location and recognise repeat visits temporarily in memory; they are not stored
in its analytics database. Country estimates may be inaccurate, for example when
visitors use a VPN.

See [GoatCounter's privacy policy](https://www.goatcounter.com/help/privacy) for
details about processing and storage. For questions about this website, contact
Ruurd Kuiper using the profile links on this site.
